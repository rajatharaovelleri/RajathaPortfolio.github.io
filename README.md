# Rajatha Rao V — Portfolio

Static portfolio site (HTML, CSS, JS). No build step.

- `index.html` — home
- `work.html` — projects
- `enotifiers.html`, `bridge-ed.html`, `second-cycle.html` — case studies
- `resume.html` — resume
- `assets/` — images, video, shared `site.css` and `site.js`

Keep `assets/` next to the HTML files. Open `index.html` to view locally.
